# Number-Guessing-Game

Solution for project on https://roadmap.sh/projects/number-guessing-game

#Introduction
Welcome to Number Guessing Game. In a command line you have 10, 5 or 3 attempts to choose a correct number between 1 to 100 that is randomly generated.

#How to run and play
1. Get the C# file in Releases
2. Run it and you will see the Welcome message
3. Choose your difficulty between 1. Easy (10 attempts) 2. Medium (5 attempts) 3. Hard (3 attempts)
4. Once you've selected your difficulty, now you will have to guess the number
5. Enter number between 1 to 100 included
6. If you entered it incorrectly, you'll be hinted if the correct number higher or lower
7. Once you've guessed the number or you run out of attempts, you'll be asked to play again or not

# Requirements

Any IDE that can run C# files (no additional libraries needed)
